# Real recordings

Clips placed here (`.wav`, `.flac`, `.ogg`, `.mp3`) are run through `test_recordings.py`. Use short excerpts of a single sustained sung note with vibrato. Clips with many notes, speech, or loud accompaniment will fail the checks.

Commit only recordings that are in the public domain or that you have the rights to.
